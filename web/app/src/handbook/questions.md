# Common questions

## Where is Code?

Look beside **Docs** in a project that has a repository you can access. General projects can use Work and Docs on their own. The Handbook's **Code** tab has a Git README you can explore.

## Can I try this without changing team work?

Yes. Open the example card in the Handbook's **Work** tab, explore the guides under **Docs**, and switch between **Read** and **Raw** in **Code**. These examples only contain material shipped with Stead.

## Can I hide this project and still read an article?

Yes. **Settings** controls whether the Handbook appears in your sidebar. Keep a bookmark to any article, or restore the project from Settings.

## How do I know a change was saved?

A draft or proposed edit still needs acceptance. After saving, reopen the Work item or page and check the saved content and revision. For code, check the commit displayed by the project.

## How does the Handbook stay current?

The guides travel with each Stead release. A maintainer can change the Markdown alongside the feature it explains. Everyone running that release reads the same version, including someone who hid the Handbook and opens it again later.
