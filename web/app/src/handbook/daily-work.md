# Work and Docs

## Find something to do

Open **My work** to see items assigned to you. To see a team's queue, choose its project and open **Work**. Expand a status group and select a title for the description and discussion. Use **Filters** to narrow a long list.

## Try a small handoff

In a project where you can edit, create a Work item such as “Check the visitor guide.” Include what to check, who should do it and how to tell that it is finished. A comment records a conversation. Set the status after the outcome is ready.

## Read or edit a page

Open **Docs**, choose a collection and select a page title. **Read** shows the saved Markdown. **Edit** lets an authorized member change the body, **Preview** shows the formatting and **Source** exposes the full Markdown. Save at Home, then reopen the page to confirm the revision. A private draft stays private until someone explicitly publishes it.

## Find it again

Use workspace **Search** for a phrase from the page or Work item. Press Enter to search and open an authorized result. The browser's Back button returns you to your previous view.
