# T01 UX contract decision

Accepted as the product/UX design contract. I found no conflicting UX decision in the current master directive, experience contract, job profile or delivery profile for the topics below. This is a source-bound design decision, not a claim that every route, migration, Run flow or golden journey is implemented, qualified or released. Native migration review remains separate.

- **Routes and old addresses.** The selected Home supplies the origin; Project, Work and repository IDs retain distinct scoped meanings. Repository routes carry both owning Project and independent Repository; a legacy repository keeps its original ID even when it equals Project. Exact files carry repository, commit and escaped path. Work is one canonical object across views. Run links carry Project/Work/Run, matching the read scope; the older Project/Run form remains recognized but unavailable when Work cannot be established. Do not guess a Work, reinterpret slash-containing IDs or expose protected existence while resolving compatibility. Retain old identities/revisions, filters and scoped in-memory navigation state; unsupported addresses get an explicit unavailable state. The five current route cases passed in the attachment host15 bundle.
- **Owner and worker.** Owner means the accountable human; Working on it means the authorized human or stable agent doing the task. Creation may remain Unassigned and must not silently assign the creator. Autonomous admission needs an explicit human owner or visibly inherited human project steward. Inheritance must remain labeled; it does not convert the worker into the owner or grant access through a display name. Agent definition, connection and Run/attempt stay distinct from principal identity.
- **Done.** Submitted/Ready for review is not Done. All declared required outcomes must be accepted and exact required checks passed; a single merged change does not satisfy several required targets. Informational links do not block completion. An authorized human may complete a non-artifact task with a note. Preserve legacy completion and its historical basis without inventing receipts; reopened/new work follows the new rule. These are coherent display and interaction decisions even while the current runtime profile is stricter or incomplete.
- **Expired proposals.** Expiry stops further worker effects/publication and does not erase history. Current read/reviewer access permits inspection. Adoption is an explicit fresh acceptance decision preserving original author, Run and digest, with current target/base/scope and required review/checks. Revoked/compromised output may remain quarantined. Adoption must neither renew old credentials nor present an old output as newly authored. Keep it visibly distinct from retrying a worker or accepting an active proposal.
- **Golden journeys.** G1 takes ordinary no-Code Work/Docs through collaboration and accepted completion, retaining drafts and reconciling lost saves. G2 takes a selected repository through exact push/review/revision/check/merge, invalidating moved-base evidence. G3 takes a named agent through real no-Code dispatch, attributable clarification, exact Markdown proposal, requested revision and independent acceptance/downstream readiness. G4 applies that review discipline to exact Code targets without self-approval or wrong-repository authority. G5 recovers accepted outcomes while fencing revoked/stale attempts and showing the smallest actual decision. Each states a next action, durable outcome and failure behavior. A deterministic process, copied brief, synthetic card or one model reply does not stand in for G3.

No additional UX design conflict blocks this T01 decision. Remaining implementation, versioned migration and observed journey evidence should retain their own package status. T02's accepted synthetic reference scope is separately recorded in `docs/urbit/evidence/2026-11-25/markdown-attachments/acceptance.json`; neither T01 nor T02 manufactures a live rollout or human-trial result. The prepared a670 release remains separate and unchanged.
