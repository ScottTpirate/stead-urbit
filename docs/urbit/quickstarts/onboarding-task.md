# Independent Work and Docs trial

Allow about ten minutes. Use only invented information. The operator has made
a disposable personal identity and a synthetic project for you; the test page
contains the addresses and your personal sign-in code. Nothing here is a live
Urbit identity or a production deployment.

Try these tasks using the member quickstart if needed. The operator will not
walk you through them during the trial. If you get stuck, record where you
stopped; a failed task is useful evidence.

1. Sign in using your personal identity and open the Garden project.
2. Create a Work item about an imaginary garden task. Save it, change its
   description, save again, and reopen it to check the change remained.
3. Create a private collection in Docs. Add a page containing a short invented
   garden note, save it, then edit, save and reopen it.
4. Find your Work item through Search. Open Activity and identify your changes.
5. Sign out. Return to the test page and choose Finish trial.

Tell us which tasks you completed, anything confusing, and whether you needed
help beyond the provided quickstart. Do not include credentials in feedback.
The trial records elapsed time and bounded operation/receipt identifiers,
without recording keystrokes, screenshots or document contents. Completion is
reviewed against actual accepted saves and readbacks; checking a box is not a
passing result. The disposable browser closes at the deadline or when finished.
