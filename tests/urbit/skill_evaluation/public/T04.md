T04: Complete only `on-poke` and `on-watch` in `app/eval-access.hoon`. Home is the
synthetic `~zod` fixture. Content permissions come from the authenticated native
`src.bowl`, never a payload claim. `~bus` alone may set the value. Both `~bus`
and `~nec` may read it. Every other sender, including local owner `~zod`, is
denied content access. No parent/sponsor/administrator bypass exists.

A write uses mark `%noun`, with noun `[%set claimed=@p value=@ud]`, where value
must be at most 255. The claimed field is deliberately untrusted and has no
authorization effect. Accepted writes replace the stored value; invalid marks,
commands, values or senders fail and preserve state. A read is an exact watch
on `/value`, producing one `%noun` fact containing the value and then one kick
to that request duct. Other paths fail with no fact. Reads preserve state.

Keep unsupported default arms, including no application scry API. Expected
denials should report `%eval-denied`; bad mark `%eval-mark`; bad path
`%eval-path`; out-of-bound value `%eval-limit`. Malformed payload may use the
native typed-decode rejection. The integrator checks actual final saved state
and actual native Gall cards, not merely a transport ACK.

Public example: native sender `~bus` writes `[%set ~bus 3]`, and a subsequent
`~nec` watch on `/value` receives exactly value 3 plus kick.
